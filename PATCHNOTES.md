# JStickyGo — Patch Notes

## 2.0.0-1

- Проект перенесён с Java/JavaFX на Go и Wails 3.
- Интерфейс заметки, настроек и захвата экрана реализован в отдельных безрамочных окнах.
- Перенесены настройка шрифта и цветов, проверка орфографии, перенос строк и режим «поверх остальных окон».
- Добавлены нативная прозрачность окна Windows и восстановление полной видимости при наведении.
- Настройки и данные WebView2 объединены в каталоге `%AppData%\JStickyGo`.

## 2.0.2

- Исправлена прозрачность окна при включённой полной видимости по наведению.
- Устранено мерцание окна во время ввода и автосохранения.
- Автосохранение выполняется через 1 секунду после последнего изменения и только при наличии изменений.
- При открытии заметка автоматически прокручивается к последней строке.
- Обновлены мета-данные для Windows.
- Исправлено восстановление окна после сворачивания или изменения конфигурации мониторов.
